# LaTeX Draft

I miss the *LaTeX Help* app, which is too ancient to work under the latest iOS unfortunately.

So I will write one in hommage to *LaTeX Help* and name it *LaTeX Draft*.

## Features

- [x] Live equation editor with syntax highlighting (GitHub light/dark theme)
- [x] Quick reference: 170+ symbols in 8 categories, rendered live, searchable, tap to copy
- [x] Mac Catalyst support — runs natively on macOS
